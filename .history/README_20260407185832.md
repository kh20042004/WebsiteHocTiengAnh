# English 12 Smart - Platform Học Tiếng Anh Thông Minh

![Java](https://img.shields.io/badge/Java-11+-blue) ![Spring Boot](https://img.shields.io/badge/Spring%20Boot-2.7+-green) ![Maven](https://img.shields.io/badge/Maven-3.6+-orange) ![License](https://img.shields.io/badge/License-MIT-green)

## 📋 Mô Tả Dự Án

**English 12 Smart** là một nền tảng học tập trực tuyến hiện đại, được thiết kế để hỗ trợ học sinh và giáo viên trong quá trình dạy và học tiếng Anh cấp 12. Nền tảng cung cấp các công cụ quản lý lớp học, bài tập, tiến độ học tập và hệ thống xác thực an toàn.

## ✨ Tính Năng Chính

### Dành cho Học Sinh
- 📚 Truy cập các bài học và nội dung học tập theo đơn vị
- ✏️ Làm bài tập và kiểm tra trực tuyến
- 📊 Theo dõi tiến độ học tập cá nhân
- 👥 Tham gia các lớp học
- 📖 Hệ thống bài học tương tác

### Dành cho Giáo Viên
- 📝 Tạo và quản lý bài tập
- 👨‍🎓 Quản lý học sinh và lớp học
- 📈 Theo dõi hiệu suất học sinh
- 📚 Tạo nội dung bài học
- 🎯 Quản lý các đơn vị học tập

### Quản Trị Viên
- 🛡️ Bảng điều khiển quản trị toàn hệ thống
- 👤 Quản lý người dùng và quyền truy cập
- 📊 Theo dõi thống kê hệ thống
- ⚙️ Cấu hình hệ thống

## 🛠️ Công Nghệ Sử Dụng

### Backend
- **Spring Boot 2.7+** - Framework web Java
- **Spring Security** - Xác thực và phân quyền
- **Spring Data JPA** - ORM và truy cập cơ sở dữ liệu
- **OAuth 2.0** - Xác thực xã hội
- **MySQL/MariaDB** - Cơ sở dữ liệu quan hệ

### Frontend
- **Thymeleaf** - Template engine cho views
- **HTML5** - Markup
- **CSS3 / Tailwind CSS** - Styling
- **JavaScript (ES6+)** - Client-side logic
- **Responsive Design** - Giao diện thích ứng

## 🚀 Hướng Dẫn Cài Đặt

### 1. Clone Repository
```bash
git clone https://github.com/yourusername/english-12-smart.git
cd english-12-smart
```

### 2. Cấu Hình Cơ Sở Dữ Liệu

Tạo database MySQL:
```sql
CREATE DATABASE english12smart;
CREATE USER 'smartuser'@'localhost' IDENTIFIED BY 'your_password';
GRANT ALL PRIVILEGES ON english12smart.* TO 'smartuser'@'localhost';
FLUSH PRIVILEGES;
```

### 3. Cấu Hình Thông Tin Kết Nối

**Bước 1:** Copy file cấu hình ví dụ:
```bash
cd src/main/resources
cp application-example.properties application.properties
```

**Bước 2:** Chỉnh sửa `application.properties` với thông tin của bạn:

```properties
# MongoDB Connection
spring.data.mongodb.uri=mongodb+srv://USERNAME:PASSWORD@cluster.mongodb.net/english_12_smart

# Cloudinary (Image Upload)
cloudinary.cloud-name=YOUR_CLOUD_NAME
cloudinary.api-key=YOUR_API_KEY
cloudinary.api-secret=YOUR_API_SECRET

# JWT Secret (Tạo key bảo mật dài)
jwt.secret=CHANGE_THIS_TO_A_LONG_RANDOM_SECRET_KEY_32_CHARACTERS_OR_MORE

# Google OAuth2 (Nếu sử dụng đăng nhập Google)
spring.security.oauth2.client.registration.google.client-id=YOUR_CLIENT_ID.apps.googleusercontent.com
spring.security.oauth2.client.registration.google.client-secret=YOUR_CLIENT_SECRET
```

> ⚠️ **QUAN TRỌNG:** File `application.properties` chứa thông tin nhạy cảm và không được commit lên Git!

### 4. Build Dự Án

```bash
mvn clean install
```

### 5. Chạy Ứng Dụng

```bash
mvn spring-boot:run
```git 

Hoặc chạy file JAR sau khi build:
```bash
java -jar target/english-12-smart-1.0.0.jar
```

Ứng dụng sẽ khả dụng tại: `http://localhost:8080`

## 🐛 Khắc Phục Sự Cố

### Lỗi kết nối cơ sở dữ liệu
- Kiểm tra MySQL server đang chạy
- Xác minh username/password trong `application.properties`
- Kiểm tra port MySQL (default 3306)

### Lỗi cổng 8080 đã được sử dụng
```bash
# Thay đổi port trong application.properties:
server.port=8081
```

### Lỗi build Maven
```bash
# Xóa cache Maven
mvn clean
# Rebuild
mvn install -U
```
